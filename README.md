Abre index.html en tu navegador para ver la sorpresa. Pulsa el botón para animar la gota, el crecimiento y la floración.
Cada pétalo lleva una frase centrada y orientada a lo largo de su forma. Las traducciones se repiten en las distintas capas, que se abren con transiciones de 0.3 segundos.
La perspectiva, las sombras y las capas crean profundidad visual. Mueve el cursor alrededor de la flor para verla inclinarse.
